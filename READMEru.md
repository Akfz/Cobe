# Cobe

**Cobe** — библиотека и анимационный движок для Minecraft, предназначенный для работы со сложными 3D-моделями и сетками (meshes). Создан как более функциональная альтернатива GeckoLib.

## Основные возможности

- **Поддержка мешей и скиннинга**: Работа с произвольной геометрией (вершины, UV-координаты, грани) и деформацией мешей на основе весов костей (*Skinned Mesh Animation*).
- **Многопоточный расчет анимаций**: Вычисления трансформаций костей происходят в отдельном пуле потоков (`AsyncAnimationEngine`) с динамической подстройкой под нагрузку, что исключает просадки FPS на основном потоке рендеринга.
- **Расширенная система анимаций**:
    - Поддержка произвольной частоты кадров (FPS) для каждой анимации, с возможностью изменяться во время её проигрывания.
    - Послойное воспроизведение (*Layers*) с поддержкой масок костей (*Bone Masks*).
    - Смешивание (*Blending*) и плавные переходы (*Fade In* / *Fade Out*).
    - Очередность воспроизведения (*Queue*) и удержание последнего кадра (*Hold on last frame*).
    - Набор функций интерполяции: `Linear`, `Step`, `Bezier`, а также Easing-функции (`Bounce`, `Elastic`, `Exponential`, `Back`, `Circular` и др.).
- **Процедурные изменения (Bone Modifiers)**: Возможность внедрять кастомные трансформации костей в реальном времени через интерфейс `BoneModifier`.
- **Видео-текстуры** (опционально; windows/linux only): Высокопроизводительный собственный нативный C++ декодер видео через JNI (`NativeVideoDecoder`). Поддерживает воспроизведение `.mp4` (H.264), `.mpg` (MPEG-1) и анимированных `.gif` прямо на текстурных картах моделей. Написан с нуля без тяжелых зависимостей вроде FFmpeg, с использованием `pl_mpeg`, `minimp4`, `OpenH264` и `stb_image` для эффективной конвертации YUV420 в RGBA.
- **Продвинутая система хитбоксов**: Поддержка сложных хитбоксов, привязанных к костям модели, через файлы формата `.hb`. Реализована высокоточная проверка коллизий на основе теоремы разделяющих осей (SAT), полностью совместимая со стандартными AABB-хитбоксами Minecraft.
- **Динамическая загрузка ресурсов**: Загрузка и парсинг моделей, анимаций и данных хитбоксов (`.hb`) из JSON во время выполнения (runtime) или через кастомные ресурспаки (`CobeCFGPack`).

**Для блендера нужен [плагин](https://github.com/Akfz/Cobe_blenderPlugin)**
